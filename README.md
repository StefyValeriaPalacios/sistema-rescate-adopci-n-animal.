Sistema de Control de Rescate y Adopción Animal

Descripción
Proyecto académico para diseñar un sistema que permita registrar y gestionar casos de rescate, atención y adopción de animales.

Objetivo
Diseñar la arquitectura lógica del sistema utilizando diagramas UML, patrones de diseño y el flujo de trabajo Gitflow.

Actores
Ciudadano o reportante.
Voluntario o veterinario.
Administrador del refugio.

Funcionalidades principales
Registrar casos de rescate.
Clasificar animales por especie.
Asignar voluntarios o veterinarios.
Actualizar el estado de los casos.
Registrar atención médica.
Generar reportes.

Diagramas
Diagrama de casos de uso.
Diagrama de clases UML.
Arquitectura general y flujo Gitflow.

Patrones de diseño propuestos
Singleton.
Observer.
Factory Method.
MVC como patrón arquitectónico.

Flujo de trabajo
Se utilizarán las ramas master, develop y feature/ para organizar las versiones del proyecto.
